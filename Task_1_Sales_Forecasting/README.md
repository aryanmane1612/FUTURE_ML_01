# Task 1 - Sales Forecasting Using Machine Learning

This project uses historical Superstore sales data to forecast future monthly sales.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- JupyterLab

## Algorithm
Random Forest Regression

## Project Deliverables
- Historical sales analysis
- Monthly sales aggregation
- Machine Learning forecasting model
- Model evaluation
- Six-month future sales predictions
- Sales visualization

## Dataset
Sample Superstore Dataset (Kaggle).
